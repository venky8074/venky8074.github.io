# BHANU AI Interactive Portfolio

## What is included
- `index.html` — portfolio page
- `style.css` — design
- `script.js` — cursor interaction
- `character.mp4` — add your own AI character video here

## To add your video
1. Create a short AI character video.
2. Rename it exactly: `character.mp4`
3. Upload it into the same folder as `index.html`.
4. Refresh the website.

The site works without the video too; it will show a fallback character.

## Free hosting
GitHub Pages can host this static website. Create a public repository, upload these files, then enable Pages from Settings → Pages → Deploy from a branch.
